Лабораторная работа №2: Базовые и продвинутые возможности CSS
Вариант: №18 («Космический энтузиаст и астроном-любитель»)
Описание проекта
В рамках лабораторной работы №2 выполнена стилизация веб-страницы «О себе» из ЛР №1 с использованием внешних стилей CSS, переменных, механизмов позиционирования, псевдоклассов, псевдоэлементов и ключевых анимаций.
Дизайн выполнен в тёмно-синей космической цветовой гамме с золотистыми акцентными элементами и интерактивным динамическим фоном.
Способы подключения стилей:
Внешний файл: style.css с основными правилами.
Внутренний блок <style>: Стиль для оформления аватара (.avatar — рамка и свечение).
Inline-стиль: style="position: relative;" для контейнера .stars-container.
CSS Переменные (:root):
--primary-bg (#0b1021) — тёмно-синий основной фон.
--secondary-bg (#ffffff00) — прозрачный фон для блоков.
--accent-color (#ffd700) — золотистый акцентный цвет.
--text-color (#e0e6ed) — светлый текст.
--font-main (Arial, sans-serif) — основной шрифт.
Типы позиционирования:
static — для подвала страницы (footer).
relative — для основного контейнера .stars-container и секций.
absolute — для мерцающих звёзд .star и фоновых псевдоэлементов.
Интерактивность и состояния элементов:
:hover — подсвечивание рамок секций, а также эффект «раздвижения/затухания» звёзд при наведении на секцию «Проекты» (.projects-section).
:active — эффект яркой световой «вспышки» при нажатии на кнопку формы обратной связи.
:focus — золотистое свечение границ текстовых полей ввода (input, textarea).
:visited — изменение цвета для посещённых ссылок (.space-link).
Звёздное небо и анимации:
Двухслойный фоновый паттерн звёзд на псевдоэлементах ::before и ::after с плавной анимацией мерцания и микро-сдвига (@keyframes twinkle-bg-1, twinkle-bg-2).
Дополнительные мерцающие звёзды (div.star) с задержками анимации (animation-delay).
Доступность (Accessibility):
Контрастность текста по отношению к фону составляет более 12:1 (при норме WCAG не менее 4.5:1).
